# turn-battle-sample

Unity 턴제 전투 샘플. 프로젝트는 `Bravo` 폴더에 있다.

## 전투 구조

| 구성 요소 | 책임 |
| --- | --- |
| `BattleManager` | 아웃게임과 인게임의 경계인 싱글톤. 아웃게임의 전투 시작 요청과 데이터를 전달하고 종료 결과를 돌려준다. 전투 내부 클래스는 Manager를 참조하지 않는다. |
| `BattleCaster` | 전투 한 판의 준비, 진행, 정리를 담당한다. 로직 초기화, 프리팹 로드, UI 연결과 행동 및 연출 순서를 조율한다. |
| `BattleRuler` | 전투 상태와 규칙을 담당한다. 배치 데이터를 기반으로 행동 선택, 턴 진행, 행동 검증, 효과 적용, 승패 판정을 수행한다. |
| `IBattleUIHandle` | 전투와 UI를 연결한다. 상태와 결과 표시뿐 아니라 필요에 따라 이벤트나 콜백으로 UI 요청도 전달할 수 있다. |
| `IBattleMotionHandle` | 인게임 캐릭터의 동작과 연출을 연결한다. |

배치 완료 → 전투 시작 요청 → 초기화 → 규칙에 따른 행동 선택과 처리 반복 → 최종 결과.

전투 시작 후에는 매 턴 UI 입력 없이 규칙에 따라 자동으로 진행한다. Caster는 UI와 모션 핸들이 연결된 경우에만 해당 동작을 호출한다. 핸들이 없으면 표현과 연출 대기를 생략하고, 데이터와 로직만으로 동일한 규칙에 따라 최종 결과를 얻는다. 피해 적용, 턴 진행, 승패 판정은 UI나 애니메이션 콜백에 의존하지 않는다.

## 현재 준비 범위

- 스크립트 위치: `Bravo/Assets/Scripts/Battle`
- `BattleManager.Instance`로 접근하는 일반 C# 싱글톤을 구현했다. 씬에 컴포넌트를 배치할 필요는 없다.
- Caster와 Ruler는 일반 C# 클래스이며, UI와 모션 핸들은 인터페이스 선언만 준비했다.
- 전투 데이터, 인터페이스 메서드와 이벤트, 실제 전투 규칙 및 프리팹/UI 연결은 후속 구현 대상이다. 현재 골격만으로 전투를 실행할 수는 없다.
- 별도의 자동 전투 설정과 전투 배속 기능은 현재 구현 범위에 포함하지 않는다.
