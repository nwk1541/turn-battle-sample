## 전투 구조

| 구성 요소 | 책임 |
| --- | --- |
| `BattleManager` | 아웃게임과 인게임의 경계인 싱글톤. 외부에 전투 시작 등의 제어 API를 제공하고, 요청과 데이터를 Caster에 전달하며 종료 결과를 돌려준다. 전투 내부 클래스는 Manager를 참조하지 않는다. |
| `BattleCaster` | 전투 한 판의 준비, 진행, 정리를 담당한다. 로직 초기화, 프리팹 로드, UI 연결과 행동 및 연출 순서를 조율한다. |
| `BattleRuler` | 전투 상태와 규칙을 담당한다. 배치 데이터를 기반으로 행동 선택, 턴 진행, 행동 검증, 효과 적용, 승패 판정을 수행한다. |
| `IBattleUIHandle` | 전투 상태와 결과를 UI에 표현하기 위한 연결 규약. |
| `IBattleMotionHandle` | 인게임 캐릭터의 동작과 연출을 연결한다. |

배치 완료 → 외부에서 BattleManager의 전투 시작 API 호출 → Caster의 초기화와 진행 조율 → Ruler의 규칙에 따른 행동 선택과 처리 반복 → BattleManager를 통한 최종 결과 전달.

외부 UI의 전투 시작 같은 제어 요청은 BattleManager를 통해 전달한다. Caster는 UI와 모션 인터페이스로 표현을 요청한다. 모션의 연출 완료 통지는 연출 대기를 끝내기 위한 신호로 사용할 수 있다.

전투 시작 후에는 매 턴 UI 입력 없이 규칙에 따라 자동으로 진행한다. Caster는 UI와 모션 핸들이 연결된 경우에만 해당 동작을 호출한다. 핸들이 없으면 표현과 연출 대기를 생략하고, 데이터와 로직만으로 동일한 규칙에 따라 최종 결과를 얻는다. 피해 적용, 턴 진행, 승패 판정은 UI나 애니메이션 콜백에 의존하지 않는다.

## 인게임 화면과 프리팹

- 원근 카메라로 Quad 바닥과 왼쪽 Player 1명, 오른쪽 Enemy 1명을 한 화면에 표시할 예정이다. 구상도의 글자는 설명용이며 화면에는 표시하지 않는다.
- 공통 캐릭터 프리팹: `Bravo/Assets/Prefabs/Battle/BattleUnitCube.prefab`. 크기 `(1, 1, 1)`의 Cube이며, 피벗이 중심이므로 바닥 높이가 0이면 Y 위치를 0.5로 배치한다.
- 검병 머티리얼: `Bravo/Assets/Materials/Battle/SwordsmanBlue.mat`. URP Lit 기반 파란색(`#3478DB`)이며 공통 프리팹의 기본 머티리얼로 적용했다.
- 병종은 공통 큐브에 적용하는 머티리얼의 배색으로 구분한다. 현재는 검병용 파란색만 준비했다.

## 모션 연출

- 공격 연출은 상대 앞까지 접근 → 공격과 피격 표현 → 원래 위치로 복귀 순서이며, 복귀까지 끝나면 완료를 통지한다.
- `IBattleMotionHandle` 구현체 내부에서 DOTween의 Sequence로 연출을 구성할 예정이다. 인터페이스와 Caster, Ruler에는 DOTween 타입을 노출하지 않는다.
- Caster는 연출 완료 후 다음 행동을 진행한다. 모션 핸들이 없으면 대기를 생략하며, 전투 중단 시에는 진행 중인 연출과 대기를 함께 정리한다.
- DOTween은 사용자가 UPM으로 별도 설치한다. 현재 프로젝트에는 설치하지 않았다.
